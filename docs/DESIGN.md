# Jay Zhou portfolio design system

Recruiter-facing editorial identity. A stable statement introduces Jay; actual work supplies proof. Natural vertical browsing replaces scroll-snapping, view-height sections, and carousels.

- Paper #f6f4ef, ink #20231f, muted #62645d, orange #b83d20.
- Dark: ink #171b18, paper #f2f1e9, muted #b7bcb4, orange #ff9874.
- Self-hosted DM Serif Display normal/italic for display; DM Sans body/UI. SIL OFL licenses included.
- 1440px max shell, 64px desktop / 24px mobile gutters, generous section spacing, 1px rules.
- Open alternating project rows; product frames only. Native disclosures for case notes and archive.
- Matching technology icons only. Text labels remain visible without hover. Plain monograms distinguish non-logo capabilities.
- Pre-paint theme initialization defaults to system preference; explicit choice persists. Reduced motion disables all transitions and smooth scrolling. Video never autoplays.
